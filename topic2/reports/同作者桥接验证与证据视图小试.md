# 同作者桥接验证与证据视图小试

*2026-11-10 · 阿里云百炼 · 两条独立实验*

## 作品作者桥接

将作品作为句子主体的明确 `play/novel/book … by` 句式纳入校验。电影基于某人写的剧本或戏剧的句式不通过新增作者规则。同作者反查要求题目询问作品、题面有唯一可匹配的起点作品、两部作品的作者原文匹配。目标证明句缺失时，才成组装入两侧出处并保护排名前五的已有原句。冻结前用 Lessing 旧开发题重放：两条作者关系恢复，自动加入《Emilia Galotti》的首句，最终 501 token 文本与此前已答对的人工回填文本逐字一致。这个旧例只做回归。

从两套官方 dev 各取 16 个此前未跑的题族。按作者措辞筛选，优先抽题面询问作品的题，未使用答案筛选。HotpotQA 16 题命中作品措辞，MuSiQue 只有 2 题命中，其余是作者相关题。编译 470 篇，94 次结构化调用。收紧句式后离线重放原 API 输出，保留 281 条过检事实。固定候选、`qwen3-rerank`、阿里云 `qwen3.5-plus-2026-04-20` 阅读器，比较完整候选、纯重排、规则桥接和 Wiki 组。224 条问答结果全部成功，97 次独立阅读调用。编译、重排和答题按记录标价折算约 0.4313 元。[冻结配置](../runs/author-bridge-heldout32/freeze.json) · [配对数据](../runs/author-bridge-heldout32/comparison.json)

## 跨题证据视图小试

从 41 个候选题族的已记录样例中选五对有明确触发词和同一原文证明句的自然题。先用首题实际重排并选出 1,024 token 证据。仅当共用证明句已入模时，将触发词、来源版本、句序写入 SQLite。第二题答案不同。比较在线重算、完全相同题面的证据缓存、命中后固定证明句并将该句排除在第二次重排之外的证据视图。另重复首题看缓存边界。五个视图全部写入，版本变化的失效断言均通过。触发词和原文证明是为这个机制小试事先人工确认的，未训练自动发现模块。

| 查询负载 | 方案 | 重排调用 | 重排输入 token | 阅读输入 token | 端到端 P50 |
|---|---|---:|---:|---:|---:|
| 相关新题 | 在线重算 | 5 | 32,048 | 5,401 | 1,235 ms |
| 相关新题 | 精确缓存 | 5 | 32,048 | 5,401 | 1,345 ms |
| 相关新题 | 证据视图 | 5 | 31,688 | 5,401 | 1,426 ms |
| 完全重复 | 在线重算 | 5 | 31,116 | 5,408 | 1,202 ms |
| 完全重复 | 精确缓存 | 0 | 0 | 5,408 | 712 ms |
| 完全重复 | 证据视图 | 5 | 30,757 | 5,408 | 1,305 ms |

相关新题视图命中 5/5，只少 **360 个重排 token（1.12%）**，未少一次调用。三组给阅读器的证据逐题完全相同，独立回答的个别措辞分数不同，不能归因于视图。计入阅读和重排时，视图与在线重算五题标价约为 0.02048 和 0.02043 元，差别受回答长度影响。表中延迟为并发小试的观测值，不含首次预热成本，未显示跨题端到端加速。完全重复题则由精确缓存直接复用整份证据，更容易省掉重排。[视图结果](../runs/semantic-view-pilot5/summary.json) · [逐题日志](../runs/semantic-view-pilot5/scored.jsonl)
